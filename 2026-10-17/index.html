01国际INTERNATIONAL
 
【重磅】
Elorian 放出 Glimpse：推理时会回头「再看一眼」视频
事件10 月 16 日（美国时间周五），Palo Alto 创业公司 Elorian 发布首款视觉推理模型 Glimpse，研究预览阶段提供 API，聊天界面需排队；TechCrunch 独家报道。
要点
•强调「视觉思考空间」：推理中途可裁切区域、回看视频短片段、用代码测量对比，而不是看一眼就改成文字硬想
•官方称小团队、几百张 GPU、基于开源权重后训练；输入/输出定价约 0.60/3.00 美元每百万 token，自测在科学图表、短视频字幕等项上可比肩甚至超过 GPT-6 Astra
•CEO Andrew Dai 曾任 Google DeepMind；公司此前以约 3 亿美元估值融到 5500 万美元种子轮，投资方包括 Striker、Menlo、Altimeter，Nvidia 与 Jeff Dean 有参与
解读
我关心的不是又一张榜单，而是它是不是把「看」做成了可循环的工具调用。多数多模态模型还是先压成 token 再纯文本推理，Glimpse 赌的是中途回去看原图。机器人、实验室录像、短视频平台会先尝鲜。不过现在是研究预览，自测数字要等第三方复现；聊天还在 waitlist，先别当生产依赖。
 
【融资】
Anthropic 路演掏出 Q3：168 亿美元营收，增速却明显放缓
事件据彭博、路透等报道，Anthropic 在旧金山向潜在投资者披露：2026 年第三季度营收约 168 亿美元，较二季度约 116 亿美元环比增长约 45%，并称调整后已实现盈利与正自由现金流。
要点
•一季度营收约 47 亿美元，二到三季度增速从翻倍级明显回落；部分投资者据此讨论估值为约 1.5 万亿美元量级，低于此前流传的约 2 万亿
•公司仍在筹备可能的 11 月前后 IPO；路透提到「思考」能力上限、蒸馏收入减少等对业绩的影响也出现在讨论里
•同一窗口，Claude Opus 5.5 Fast Mode 对开发者全面放开，溢价卖速度
解读
数字看着炸裂，市场却在盯增速斜率。我读下来，这更像成熟期的故事：企业大单在，但「每个季度翻一番」那套叙事不好讲了。对后面定价和锁定期的预期会更苛刻。另说一句，调整后盈利不等于 GAAP 利润，股权激励那些大头还得单独看。
 
【产品】
Claude Opus 5.5 Fast Mode 开闸：同模型，最高约 2.5 倍输出吞吐
事件Anthropic 平台文档确认：Claude Opus 5.5 的 Fast Mode 无需再申请或带 beta 头，请求里设 speed: "fast" 即可；Start/Build/Scale 档位有默认快速模式配额。
要点
•官方称最高约 2.5 倍输出 tokens/秒，权重与能力不变，主要提 OTPS 而非首 token 延迟
•定价：输入 8 美元、输出 40 美元每百万 token（标准价之上的溢价档）；有独立速率限制
•已支持 Claude API 与 Azure 上的部分部署；Batch、Priority Tier 等场景不可用
解读
这是把「愿意多付钱换延迟」产品化了。写代码、Agent 循环这种吃输出长度的场景最有感。我会盯两件事：快慢模式不共享 prompt cache，来回切很亏；以及 429 时要不要自动回落到标准速度。钱花在刀刃上才值。
 
【产品】
谷歌给 AI Mode / AI Overviews 加更多出处链接
事件10 月 15 日，Google Search 产品博客宣布更新 AI Mode 与 AI Overviews：内联链接更靠前、更频繁，并测试在回答顶部突出「官方/关键」站点。
要点
•时事新闻轮播将扩到更多地区与语言，并优先展示用户设定的 Preferred Sources
•回答末尾相关文章链接触发更醒目；AI Mode 开始测试可点击的创作者/出版方主页
•谷歌称 Preferred Sources 使用人数较年初增长逾 7 倍
解读
表面是体验优化，实质是给出版方一点流量喘息。AI 摘要吃掉点击这件事吵了很久，多放链接是妥协也是防御。对我这种读者来说是好事——摘要看完能直接点进原文核对。真正会不会回流到媒体腰包，还得看点击分布，不是看公告措辞。
 
【关注】
ChatGPT 广告能按邮箱名单和提示词兴趣定向了
事件404 Media 实测并报道：ChatGPT 广告支持广告主上传邮箱、手机号或 Android 广告 ID 做自定义受众，也可按提示词相关的兴趣描述匹配；OpenAI 帮助中心与广告文档同步说明了 Custom Audiences。
要点
•名单可上传明文或 SHA-256 哈希；匹配人数超过约 2.5 万才能做正向定向，更小的名单多用于排除
•另有「情境提示」：广告主描述主题/关键词，OpenAI 称用于引导匹配而非精确关键词投放
•OpenAI 称处理完通常 24 小时内删除上传文件，广告主看不到具体匹配到谁；用户可关闭基于历史对话的个性化，但当前会话仍可能影响广告
解读
广告这天迟早要来，只是邮箱上传这一步比很多人以为的更「社交网络」。404 自己买广告吐槽隐私，挺黑色幽默。我个人会默认：付费对话也不等于绝对隐私。企业客户要是在 ChatGPT 里贴客户名单，合规同学该紧张一下了。
 
【政策】
FBI 与 CISA 提醒：中期选举前当心 AI 加持的钓鱼与换脸
事件10 月 16 日，美国联邦调查局（FBI）与网络安全和基础设施安全局（CISA）联合提示选举官员与竞选团队，防范利用 AI 增强的网络攻击与欺诈，面向即将到来的中期选举。
要点
•威胁包括高度仿真的钓鱼邮件/短信、深度伪造音视频，用于骗取凭证、敏感数据或植入恶意软件
•IC3 另有提示：骗子可能用 AI 生成的候选人声音、形象诱骗捐款或收集个人信息
•官方建议提高对异常请求的核验，并走既有事件上报渠道
解读
选战季的老剧本加上新工具。监管层已经默认「AI 伪造足够骗过人」了。对企业安全团队也有映射：对外发言人、CEO 声纹被克隆的风险，别等到出事再写预案。
 
02国内CHINA
 
【重磅】
两部门拟把 AI 等 40 项技术写入出口管制目录，先征求意见
事件10 月 16 日，商务部、科技部发布 2026 年第 48 号公告，就修订《中国禁止出口限制出口技术目录》公开征求意见，并对相关技术出口实施临时登记管理；新华社等同步报道。
要点
•拟增列人工智能、生物医药、光伏三个领域共 40 项技术：拟禁止出口 14 项、限制出口 26 项；其中 AI 相关约 23 项，涵盖大模型、智能体、算力集群、信息处理等
•发言人举例：AI 驱动的恶意代码生成与变异技术拟禁止；AI 辅助漏洞挖掘等拟限制；已开源或论文公开进入公域的技术拟不纳入管理，部分情形可适用自动许可
•正式目录实施前，相关技术出口须先在商务部系统登记；征求意见截止约 11 月 15 日。对 API/SaaS/端侧轻量化等多数「出海」形态，官方称若未发生限制类技术跨境转移则不按大模型技术出口管
解读
这是今天国内权重最高的一条。方向很清楚：管敏感能力扩散，同时给开源和境外自建算力留口子。对企业法务来说，先别等正式稿，临时登记这周就可能碰上。我建议各家立刻盘点：权重交付、海外本地化部署、合资公司控股权变更，这三类最容易踩线。
 
【关注】
17 岁陈广宇离开 Kimi，否认下家是 Anthropic
事件10 月 15 日，参与月之暗面 Kimi 核心架构工作的 17 岁研究员陈广宇在社交媒体宣布已离开团队；观察者网、界面新闻等 16 日跟进。
要点
•他回顾在 Kimi 的一年是「最美好的时光」，提及参与 KDA（Kimi Delta Attention）优化与 Attention Residuals 相关研究，并感谢公司在其 16 岁时给予机会
•Attention Residuals 论文中他是共同一作之一，该工作被视为支撑 Kimi K3 的关键架构之一
•Anthropic 研究员 Sholto Douglas 在评论区邀他加入；陈广宇称将前往湾区，但 16 日明确回复「不会」加入 Anthropic，具体下家未公开
解读
少年离开头部实验室，行业八卦属性拉满，但我更在意信号：顶尖架构人才的流动已经高度全球化，年龄不是门槛。月之暗面留人靠的是课题和信任，不是工牌。下一站无论是哪家，湾区这条路径会更常被复制。
 
03开源与科研OPEN SOURCE & RESEARCH
 
【产品】
Black Forest Labs 开源 FLUX 3 Image Klein：5.6B，能跑在 8GB 显卡上
事件10 月 15 日，Black Forest Labs 发布 FLUX 3 Image Klein 开放权重：5.6B 参数，支持文生图、编辑与最多 10 张参考图的多参考生成。
要点
•与完整版 FLUX 3 Image 共享原生约 4K、像素级编辑、边界框布局控制等能力；提供 base（可微调）与 step-distilled（低延迟）以及 FP8/INT8/NVFP4 构建
•官方称 INT8 可在约 8GB 显存的 GeForce 上通过 ComfyUI/Diffusers 运行；蒸馏版在 RTX 5090 上约 4 秒出 1MP 图
•许可证为 FLUX Kommunity License：年收入低于 500 万美元的个人/公司可免费商用产出，更大组织需商业授权或走 API
解读
开源文生图又回到「小参数、能本地跑」这条产品线上。注意它不是 Apache：Communuity 许可有营收门槛，大厂别想无脑商用。对个人创作者和中小工作室倒是实在，编辑+多参考这一套比纯文生图更接近工作流。
 
【关注】
OpenAI 给生命科学实验室送 Rosalind；Simons 联手两家投 1500 万美元帮数学界
事件10 月 15 日前后，OpenAI 推出 Rosalind Academic Plan；同日 Simons 基金会宣布与 OpenAI、Anthropic 共同投入合计约 1500 万美元及算力资源，帮助数学共同体应对 AI 生成研究。
要点
•Rosalind：符合条件的美国大学实验室可申请最多 30 个 ChatGPT Business Standard 席位，最长约 12 个月免费；GPT-Rosalind 需通过可信访问审批，默认不用研究数据训练，暂不含 API
•Simons：基金会负责管理与立项，支持研讨班、工具与评估标准；两家公司另提供模型与算力，范围可延伸到基础科学
•背景是 AI 产出数学文稿激增，学界需要共同规则来核验与吸收
解读
一个给湿实验，一个给干数学，都是「把前沿模型塞进学术工作流」。Rosalind 的审查门槛说明生命科学仍被当成高敏感场景。Simons 这笔钱我更看好：与其让实验室单打独斗应对 AI 灌水，不如先把评价标准社区化。
 
【关注】
Claude Mythos 5 花 53 小时「闭路」优化量子电路，门数最多砍到约 1/17
事件10 月 16 日，Anthropic 发文介绍 STEM Fellows 项目成果：研究员 Andi Gu 等与哈佛、QuEra 合作，让 Claude Mythos 5 在自动评测闭环里设计量子电路；论文已上 arXiv。
要点
•只给自然语言规格与可自动打分的评测器，模型自主提议、验证、迭代；八项任务里多项相对已发表最优设计有数量级改进
•椭圆曲线点加相关设计中，有方案相对此前最小设计多用约 12% 量子比特，但门数减少约 17 倍；另在 DQI 解码器上相对谷歌先前构造把门数降到约 1/12
•单次椭圆曲线相关探索运行约 53 小时；部分结果用 Lean 等形式化手段复核
解读
这不是「AI 发现新物理」的口号稿，而是电路编译层面的工程加速。量子硬件很贵，算法侧每砍一个数量级的门，实用时间表就往前挪一点。局限也很清楚：任务得能自动验证正确性；换到更开放的科研问题上，这套闭环未必好使。
 
【产品】
OpenUI 1.0 开源：让 Agent 直接吐可交互界面，而不是大段文字
事件OpenUI 1.0（Thesys 等维护）以 MIT 许可发布：模型可流式输出紧凑的 UI 程序，由你注册的组件渲染成卡片、表单、图表等交互界面。
要点
•1.0 增加自定义函数 defineFunction、自定义动作 defineAction、library.extend 与消息解析等；React 侧跟进较全
•定位是生成式 UI 开放标准/运行时，减少 Agent 应用里「全文 JSON 再手写渲染」的成本
•同期有报道称其基准上相对部分 JSON 渲染格式可减少约一半 token（第三方测评，需自行验证）
解读
Agent 产品下一步拼的是交互，不是又写一封长邮件。OpenUI 这类标准要是真能统一几家前端栈，工具型 Agent 会好做很多。现在生态还早，Vue/Svelte 等跟进速度不一，选型前先看你的组件库能不能接上。

编辑点评观点

周六这期的主轴，我概括成四个字：管与用。国内出口目录征求意见，把大模型、智能体、算力集群写进清单；美国这边则是选举安全提示和广告定向——一边防滥用，一边把同一套能力卖成商业闭环。

产品侧反而更「看见」与「界面」：Glimpse 赌视觉闭环，OpenUI 赌生成式 UI，FLUX Klein 把开源文生图又压回消费级显卡。谁先把工作流做短，谁就有下一波开发者。

学术线也没闲着。Rosalind 和 Simons 的钱，本质是给实验室买时间与规范。AI 已经能灌数学稿、改量子电路了，人类这边得先把验收标准立起来，不然只会更乱。

个人看法，不构成投资建议。
